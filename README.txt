NEXUS FITNESS COURT website
=============================

Files:
- index.html  Main one-page website
- style.css   Responsive visual design
- script.js   Mobile navigation and current year

How to preview:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Internet is required for Google Fonts and the remote photo URLs.

How to publish:
- Upload the three files to the public_html / htdocs folder of your hosting, or
- Upload them to a GitHub repository and enable GitHub Pages.

Before publishing, please verify:
- Current membership fees and what each plan includes.
- Gym timings and facilities.
- Phone/WhatsApp number and Instagram handle.
- Address and map pin.
The site currently uses the details supplied in the conversation. Membership prices are marked indicative.
Photos are remote stock imagery and should be replaced with actual NEXUS gym photos for the final version.
